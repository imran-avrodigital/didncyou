# Didn't See You

A small sneaky-walking game. Walk past the people without being spotted, reach the green EXIT, and collect points for sneaking up right behind someone.

## Play

Open `index.html` in any browser. No install or build step needed.

- Move: arrow keys, WASD, or click/tap where you want to go
- Spotted by someone (you are inside their vision cone) costs a heart
- Walk directly behind someone to get "Huh? Didn't see you!" for +50 points
- Reaching the EXIT clears the level for +100 points

## Deploy

This is a static site, so it can be hosted anywhere (for example Vercel) with no build settings.
